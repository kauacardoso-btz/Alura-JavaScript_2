# Alura JavaScript 2

Repositório de estudos e exercícios práticos do curso **JavaScript: conhecendo arrays**, da Alura.

## Propósito

Este repositório registra o aprofundamento dos estudos sobre arrays em JavaScript, reunindo exemplos escritos durante o curso para consolidar os conceitos e servir como material de consulta.

Mais do que armazenar códigos prontos, o objetivo é evidenciar o aprendizado sobre como criar, consultar, alterar, percorrer e transformar coleções de dados usando os recursos da linguagem.

## Aprendizados

- criação e acesso a arrays por índice;
- alteração de listas com `push`, `pop` e `splice`;
- extração e combinação de dados com `slice` e `concat`;
- busca e filtragem com `includes`, `indexOf` e `filter`;
- arrays de duas dimensões e desestruturação;
- laços de repetição com `for`, `for...of` e `forEach`;
- métodos de callback como `map` e `reduce`;
- cópia de arrays com o *spread operator* (`...`);
- coleções de valores únicos com `Set`.

## Como executar

Com o Node.js instalado, execute qualquer exemplo diretamente pelo terminal:

```bash
node nome-do-arquivo.js
```

Por exemplo:

```bash
node set.js
```
